# قاعدة إتقان على Supabase

تُستخدم `auth.users` لهويات المستخدمين، و`public.users` لملفاتهم، و`public.schools` للمدارس. قيمة `education_department` اختيارية.

تُطبّق قواعد RLS على جداول المشروع، وتُقرأ العضويات من `public.school_memberships`، والأدوار العامة من `public.user_roles`. لا تمنح الواجهة دورًا أو مدرسة للمستخدم.

ملفات `migrations/` مطابقة لإصدارات قاعدة المشروع المسجّلة؛ يلزم إبقاؤها ثابتة للحفاظ على سجل الترحيلات وتطابق إعادة البناء. عند تعديل المخطط أنشئ ملفًا جديدًا فقط، وافحص التغيير ببيئة معزولة تحتوي سجلات اختبارية قبل التطبيق.

لا تُشغّل أوامر إعادة البناء المدمرة على قاعدة إتقان السحابية. إجراء منح أول مدير يمر بصلاحية خادم موثوقة، وبعد التحقق من ملكية الحساب، وليس من المتصفح.
