# خارطة متابعة تنفيذ إتقان سمارت برو — 11 نوفمبر 2026

> هذه وثيقة متابعة تقنية مشتقة من `AGENTS.md` و`README.md` ومهام GitHub #9–#21. ليست بديلاً عن خارطة طريق إدارية غير موجودة ضمن الملفات المفحوصة. حالة «منفذ برمجيًا» لا تعني قبولًا تشغيليًا أو بصريًا.

## ثوابت التنفيذ
- Cloudflare Workers للواجهات والخادم؛ Supabase Auth/PostgreSQL/Storage هو المصدر الوحيد للحسابات والبيانات والصلاحيات.
- تحقق من الجلسة على الخادم، وRLS مع كل قراءة وكتابة. جلسة HttpOnly/Secure، دون كشف أسرار.
- لا سجلات تجريبية أو ملفات شخصية في المستودع أو قاعدة الإنتاج. كل تغيير في المخطط بترحيل جديد.
- عدم المساس بنطاق أو خدمات حضوري سمارت برو أو إعدادات DNS دون تفويض.
- خط Cairo محلي للعرض وخط Tajawal محلي للطباعة.
- فصل اختبارات البرمجة وCI عن القبول التشغيلي الحقيقي؛ مؤجلة الأخيرة حسب قرار المالك.

## قائمة التأجيل الملزمة
1. كل اختبار بصري حقيقي على الكمبيوتر أو الجوال، بما فيه اختبارات النوافذ المنبثقة والتجاوب.
2. الاختبارات التشغيلية ذات الحسابات الحقيقية التي لا يمكن محاكاتها بأمان في قاعدة معزولة.
3. استيراد/اعتماد معايير رسمية أو تفويضات وصلاحيات إدارية تتطلب قرار مالك المشروع.
4. نشر إنتاجي أو تغيير DNS أو تطبيق ترحيل على قاعدة فعلية دون مراجعة تفويض النشر.
