# إتقان سمارت برو

منصة مدرسية تعتمد **Cloudflare Workers** لتقديم الموقع والواجهات الخلفية وإدارة الجلسات، و**Supabase** للمصادقة وقاعدة PostgreSQL.

## المكونات

- `src/worker.js`: واجهة الخادم، مصادقة Supabase، ملفات تعريف الارتباط الآمنة، التفويض والاستعلامات.
- `public/`: واجهة عربية متجاوبة بخط Cairo، وصفحات الدخول وإنشاء الحساب والمساحات المصرح بها.
- `supabase/migrations/`: تعريفات مخطط PostgreSQL والسياسات المتوافقة مع سجل قاعدة إتقان.
- `tests/`: تحقق تلقائي من المصادقة والصلاحيات والواجهات الخلفية.

المدرسة هي الكيان التنظيمي الأساسي. `schools.education_department` حقل اختياري. الأدوار والصلاحيات تُفرض عبر Supabase Auth وRLS.

## إعداد Cloudflare

1. صِل المستودع بمشروع Cloudflare Workers أو انشر بواسطة Wrangler. لا تُستخدم GitHub Pages لاستضافة التطبيق.
2. اضبط المتغيرين `SUPABASE_URL` و`SUPABASE_PUBLISHABLE_KEY` في بيئة Cloudflare Worker.
3. فعّل نطاق التطبيق عبر Cloudflare من لوحة المشروع بعد مراجعة DNS.
4. راجع إعدادات Supabase Auth وعنوان الموقع وروابط الرجوع المسموح بها للنطاق.
5. نفذ `npm test` قبل `npx wrangler deploy`.

لا تُضع `service_role` أو `sb_secret_*` أو كلمات المرور أو بيانات المستخدمين في المشروع أو متغيرات الواجهة.

## الجلسات

تُدار الجلسات من Cloudflare Worker بواسطة ملفات تعريف ارتباط `HttpOnly; Secure; SameSite=Lax`. تصل الواجهة إلى `/api/session` و`/api/schools` دون تلقي رموز Supabase. يُتحقق من الصلاحيات في الخادم ثم بواسطة سياسات RLS في قاعدة البيانات.

إنشاء الحساب لا يمنح عضوية مدرسة أو امتيازات إدارية. تُمنح الأدوار عبر عملية إدارية موثوقة فقط.

## بدء العمل

```sh
npm test
npx wrangler dev
```

تحتوي قاعدة Supabase على سجل الترحيلات المطبق؛ لا تنفّذ إعادة تهيئة مدمرة عليها. أضف ترحيلًا جديدًا لأي تغيير لاحق بعد اختبار حفظ السجلات.

## النشر

يتولى Cloudflare Workers Builds نشر الفرع `main` باستخدام `npx wrangler deploy`، مع تحميل إعدادات `wrangler.jsonc`. تأكد من نجاح نشر Worker الذي يحتوي على `src/worker.js` قبل تفعيل خدمات الحسابات.
